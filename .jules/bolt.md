## 2024-03-05 - Avoid layout thrashing in high-frequency event handlers by caching positions relative to the document
**Learning:** High-frequency event handlers such as `requestAnimationFrame`, `mousemove`, and `touchmove` cause significant performance jank and layout thrashing when calling `element.getBoundingClientRect()` repeatedly, forcing the browser to synchronously recalculate layout on each call.
**Action:** Always precalculate and cache element bounds (e.g. `baseX`, `baseY`, `baseTop`) relative to the document (by adding `window.scrollX`/`window.scrollY` to the `rect` metrics). Subtract the current scroll offset dynamically in the animation/update loops to find the exact viewport-relative positions without asking the browser for layout recalculation. Update these cached values only during layout changes like `window.resize` and `document.fonts.ready`.
